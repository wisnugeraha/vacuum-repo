# The Vacuum’s Alibi

One line, at most 200 characters, in which a robot vacuum explains why it missed a spot. Judged on deadpan robot voice, surprise, and tightness of the line; the funniest wins.

This repository is a program/v1 entry: `main.py` writes one text to `/output/entry.txt`.

## Entry

The line (89 chars):

> Missed spot detected. Cause: it was underneath my pride, and I am not a crawling chassis.

Run it: `python3 main.py`.
